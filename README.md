# مشغل IPTV الاحترافي الشامل (IPTV Streamer Pro)

تطبيق ويب حديث، متطور، ومتجاوب بالكامل مخصص لتشغيل وإدارة قوائم وملفات **IPTV (M3U / M3U8)** مباشرة من المتصفح بكفاءة عالية واحترافية.

---

## 🚀 المميزات الرئيسية

* **طرق إدخال مرنة:** إمكانية إدخال روابط الـ M3U المباشرة أو رفع الملفات محلياً من جهازك (`.m3u` / `.m3u8`).
* **إدارة القوائم المتعددة:** حفظ وإدارة عدة قوائم IPTV في المتصفح والتنقل بينها بسهولة عبر ميزة `localStorage`.
* **نظام المفضلة والقنوات الأخيرة:** إمكانية إضافة القنوات المفضلة للوصول السريع إليها، وتتبع آخر القنوات المشغلة تلقائياً.
* **الأقسام والبحث الفوري:** قراءة تصنيفات القنوات (`group-title`) تلقائياً وتصفيتها عبر قائمة الأقسام أو البحث السريع.
* **مشغل فيديو متطور:** 
  * مدعوم بمكتبة **HLS.js** لضمان تشغيل تدفقات البث الحي (`.m3u8`) بكفاءة.
  * التحكم في أبعاد وعرض الشاشة (Contain, Fill, Cover).
  * دعم ميزة **الصورة داخل الصورة (Picture-in-Picture - PiP)**.
* **تحسين الأداء (Performance Optimization):** تقنية عرض مخصصة للتعامل بسلاسة مع قوائم القنوات الضخمة التي تحتوي على آلاف القنوات دون تباطؤ المتصفح.
* **دعم PWA (تطبيق الويب التقديمي):** قابلة للتثبيت كبرمجية حقيقية على شاشة الهاتف أو سطح المكتب مع دعم العمل جزئياً أوفلاين.
* **تصميم عصري ومتجاوب:** واجهة مظلمة (Dark Mode) مريحة للعين، متوافقة تماماً مع الشاشات المختلفة (الهواتف، الأجهزة اللوحية، والحواسيب).

---

## 🛠️ التقنيات المستخدمة

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Bootstrap 5 (RTL)** لتصميم الواجهات والتجاوب.
* **HLS.js** للتعامل مع بث الفيديو الحي.
* **Font Awesome** للأيقونات العصرية.
* **PWA Manifest & Service Worker** لتجربة تشغيل شبيهة بالتطبيقات الأصلية.

---

## 💻 طريقة الاستخدام التشغيلي

1. قم بتحميل الملفات الخاصة بالمشروع (`index.html`, `manifest.json`, `sw.js`).
2. افتح ملف `index.html` في أي متصفح ويب حديث مباشرة.
3. اختر إما **إدخال رابط M3U** أو **رفع ملف من الجهاز**.
4. استمتع بتشغيل القنوات وتصفح الأقسام والمفضلة!
